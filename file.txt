## Setup Instructions:

1. **Create the folder structure:**
```bash
mkdir -p portfolio/static/{css,js,images,resume}
mkdir -p portfolio/templates
```

2. **Create all the files and copy the content:**
   - Copy each code section into its respective file
   - Place your resume PDF as `static/resume/prakash_resume.pdf`

3. **Install Flask:**
```bash
pip install Flask
```

4. **Run the application:**
```bash
cd portfolio
python app.py
```

5. **Open your browser:**
   Navigate to `http://127.0.0.1:5000`

## Troubleshooting

### If you get "Module not found" error:
```bash
pip install Flask
```

### If styles are not loading:
- Check that `style.css` is in `static/css/`
- Clear browser cache (Ctrl + Shift + R)

### If JavaScript animations aren't working:
- Check that `main.js` is in `static/js/`
- Open browser console (F12) to check for errors

### If resume download doesn't work:
- Make sure your PDF is at: `static/resume/prakash_resume.pdf`
- Check file permissions

## Deployment Options

### Deploy to PythonAnywhere (Free):
1. Sign up at pythonanywhere.com
2. Upload your files

### Deploy to Heroku:
1. Add `Procfile`:
   ```
   web: python app.py
   ```
2. Add `runtime.txt`:
   ```
   python-3.11.0
   ```
3. Deploy via Git

### Deploy to Render:
1. Connect your GitHub repo
2. Select Python environment
3. Set build command: `pip install -r requirements.txt`
4. Set start command: `python app.py`
